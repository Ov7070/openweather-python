# OpenWeather API Project

A simple Python project that gets weather information for a city using the OpenWeather API.

## Features

- Get weather information for any city
- Use OpenWeather API
- Display HTTP status code
- Display API response as JSON

## Requirements

- Python
- requests library
- OpenWeather API key

## How to Run

Install the required library:

pip install -r requirements.txt

Then run:

python weather.py

The program will ask for:

1. Your OpenWeather API key
2. The city name

## Technologies

- Python
- HTTP
- REST API
- OpenWeather API
